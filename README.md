# CppME Chapter 15

This repository contains a small set of C++ example programs for Chapter 15 of the "C++ Programming Made Easy" series. The examples focus on fundamental C++ programming concepts related to control flow, validation, and exception handling.

## About the project

The project is organized as a Visual Studio solution with a main application and several standalone example programs. Each example demonstrates a different way to handle invalid input and error conditions in C++.

## Repository structure

- `CppME_Chapter15.cpp` – default Visual Studio starter program (simple Hello World template)
- `CppME_Chapter15.slnx` – solution file for the project
- `CppME_Chapter15.vcxproj` – main project configuration file
- `CppME_Chapter15.vcxproj.filters` – Visual Studio filters file
- `CppME_Chapter15_Example15.9/` – example for division by zero using conditional checks
- `CppME_Chapter15_Example15.17/` – example for division by zero using `try`/`catch`
- `CppME_chapter15_Example15.25/` – example using a helper function that throws an exception
- `CppME_Chapter15_Example15.26/` – example validating a mark range using exception handling

## Example overview

### 1. Main project
`CppME_Chapter15.cpp`

This is a simple template generated by Visual Studio. It prints:

```cpp
Hello World!
```

It is a basic starting point and helps confirm that the project compiles and runs correctly.

### 2. Example 15.9 – Division by zero without exceptions
`CppME_Chapter15_Example15.9/CppME_Chapter15_Example15.9.cpp`

This example reads two integers and checks whether the divisor is zero before performing division. If the divisor is zero, it prints an error message instead of dividing.

Key idea:
- Use an `if` statement to guard against invalid division.
- Prevent runtime crashes by validating input values.

### 3. Example 15.17 – Division by zero with exceptions
`CppME_Chapter15_Example15.17/CppME_Chapter15_Example15.17.cpp`

This example uses C++ exception handling:

```cpp
try
{
    if (b == 0)
    {
        throw "Division by zero is not allowed.";
    }

    cout << "Result = " << a / b << endl;
}
catch (const char* errorMessage)
{
    cout << "Error: " << errorMessage << endl;
}
```

The program throws a string message when the divisor is zero and catches it to display a friendly error.

### 4. Example 15.25 – Throw from a helper function
`CppME_chapter15_Example15.25/CppME_chapter15_Example15.25.cpp`

This example separates the division logic into a function called `divideNumbers()`. The function checks for division by zero and throws an exception if needed.

This demonstrates:
- reuse of logic in a helper function
- exception propagation from a called function
- cleaner separation between calculation and error handling

### 5. Example 15.26 – Validate a mark range
`CppME_Chapter15_Example15.26/CppME_Chapter15_Example15.26.cpp`

This example asks the user to enter a mark between 0 and 100. If the value is outside the valid range, the program throws an error message and catches it.

Key idea:
- validate user input using constraints
- use exceptions to handle invalid values cleanly

## Learning focus

This chapter introduces or reinforces several important C++ concepts:

- `if` / `else` validation logic
- runtime error prevention
- exception handling with `try`, `throw`, and `catch`
- input validation for user-provided values
- function-level error handling

## How to build and run

### Option 1: Visual Studio (recommended for this repository)

1. Open `CppME_Chapter15.slnx` in Visual Studio.
2. Build the solution.
3. Run the program from the IDE.

### Option 2: Command line (general C++ compiler)

Compile a specific example, for example:

```bash
g++ -std=c++17 CppME_Chapter15_Example15.17/CppME_Chapter15_Example15.17.cpp -o example15_17
./example15_17
```

## Notes

This project is a learning repository and is intentionally small and focused. It is best suited for students or beginners learning the basic mechanics of C++ exceptions, validation, and flow control.

This repository is a practical collection of chapter exercises showing how to handle invalid values and runtime errors in C++. The examples gradually move from basic guard checks to more robust exception-based solutions.
